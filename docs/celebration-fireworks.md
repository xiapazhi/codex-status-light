# 完成烟花效果

## P0：托盘锚点和透明窗口

已实现内容：

- 沿用现有托盘图标 `hWnd + uID` 定位，不创建第二个托盘图标。
- 使用 `Shell_NotifyIconGetRect` 获取托盘图标真实矩形。
- 读取图标所在显示器、工作区和 DPI。
- 创建 `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TOPMOST` 透明覆盖窗口。
- 使用 32 位顶向下 BGRA DIB 和预乘 Alpha 绘制 P0 柔和圆点。
- 定位失败按立即、80ms、160ms 最多三次尝试；失败只记录诊断，不猜测位置。
- 播放完成后隐藏覆盖窗口并停止烟花定时器。
- “复制诊断信息”追加 Celebration 诊断字段。

测试入口：

- 右键托盘图标，点击 `测试完成烟花`。
- 预期在托盘图标上方出现约 1 秒柔和圆点。
- 覆盖窗口不抢焦点、不拦截鼠标、不进入任务栏和 Alt+Tab。

未进入 P0 的内容：

- 火箭升空、尾焰、主爆炸、二次爆点和余辉。
- 成功、失败、取消的正式状态接入。
- 用户开关、冷却、减少动画、全屏和勿扰策略。
