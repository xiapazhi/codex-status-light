# 完成烟花效果

## P0：托盘锚点和透明窗口

已实现内容：

- 沿用现有托盘图标 `hWnd + uID` 定位，不创建第二个托盘图标。
- 使用 `Shell_NotifyIconGetRect` 获取托盘图标真实矩形。
- 读取图标所在显示器、工作区和 DPI。
- 创建 `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TOPMOST` 透明覆盖窗口。
- 使用 32 位顶向下 BGRA DIB 和预乘 Alpha 绘制 P0 柔和圆点。
- 定位失败按立即、80ms、160ms 最多三次尝试；失败只记录诊断，不猜测位置。
- 播放完成后隐藏覆盖窗口并停止烟花定时器。
- “复制诊断信息”追加 Celebration 诊断字段。

测试入口：

- 右键托盘图标，点击 `测试完成烟花`。
- 预期在托盘图标上方出现约 1 秒柔和圆点。
- 覆盖窗口不抢焦点、不拦截鼠标、不进入任务栏和 Alt+Tab。

未进入 P0 的内容：

- 火箭升空、尾焰、主爆炸、二次爆点和余辉。
- 成功、失败、取消的正式状态接入。
- 用户开关、冷却、减少动画、全屏和勿扰策略。

## P1：点火与升空

已实现内容：

- 增加 `FireworkAnimator`、`FireworkScene` 和 `FireworkRenderer`。
- 火箭从托盘锚点发射，使用 `EaseOutCubic` 前快后慢升空。
- 轨迹带轻微横向弧线。
- 点火阶段生成短寿命暖色粒子。
- 升空阶段每帧生成 2～4 个尾焰粒子。
- 尾焰使用指数阻力、重力、短拖尾和自然淡出。
- 渲染器负责 DIB、预乘 Alpha、软光点和拖尾；overlay 只负责透明窗口和 `UpdateLayeredWindow`。
- 检测到 500ms 以上大帧间隔时直接结束动画，避免休眠恢复后粒子跳飞。

测试入口：

- 右键托盘图标，点击 `测试完成烟花`。
- 预期能看到从托盘图标附近点火、火箭升空和连续尾焰。

未进入 P1 的内容：

- 主爆炸、冲击波、流星粒子、二次爆点和余辉。
- 正式成功状态接入和成功/失败/取消区分。
- 冷却、用户开关、减少动画、全屏和勿扰策略。

## P2：主爆炸

已实现内容：

- 增加三组固定爆炸主题：`GoldWhite`、`BlueGold`、`PurpleRose`。
- 火箭升空结束后触发强光核心。
- 增加冲击波绘制。
- 主火花按环形均匀分布，并加入轻微角度扰动。
- 增加 6～8 个长拖尾流星粒子。
- 增加 8～12 个细碎亮点。
- 爆炸粒子使用重力、阻力、淡入淡出和半径衰减。
- 诊断信息记录本次 palette、seed、峰值粒子数和动画时长。

测试入口：

- 右键托盘图标，点击 `测试完成烟花`。
- 预期能看到点火、升空、中心强闪、环形扩散、少量长拖尾流星和冲击波。

未进入 P2 的内容：

- 2～3 个二次爆点。
- 后半段余辉下落的专门粒子层。
- 正式成功状态接入和成功/失败/取消区分。
- 冷却、用户开关、减少动画、全屏和勿扰策略。

## P3：二次爆点与余辉

已实现内容：

- 主爆炸后生成 2～3 个延迟二次爆点。
- 二次爆点在 120ms～220ms 后触发，生成小范围细碎粒子。
- 增加 ember 余辉粒子，低初速、高重力、暖色衰减。
- 后半段通过粒子自然过期结束，不突然隐藏。
- 粒子总数继续限制在 96 以内。

测试入口：

- 右键托盘图标，点击 `测试完成烟花`。
- 预期主爆炸后能看到少量小爆点，末尾有暖色余辉下落并淡出。

未进入 P3 的内容：

- 正式成功状态接入和成功/失败/取消区分。

## P4：正式状态接入

已实现内容：

- 增加 `AggregateTransition` 和 `CelebrationVisualState`，烟花触发不直接依赖托盘绿色视觉。
- 本地 Codex 与 Web 对话统一通过托盘聚合结果进入庆祝控制器。
- `PromptItem` 增加完成结果：成功、失败、取消。
- 成功完成才会进入待庆祝状态。
- 失败和取消仍可显示为绿色完成提示，但不会触发烟花。
- 如果成功完成时仍有其他任务运行或等待，只记录待庆祝成功；等全部进入完成态后播放一次。
- 程序启动时建立成功完成基线，不回放历史绿色状态。
- 对一次刷新内快速完成的任务做兜底：如果检测到新成功且当前没有运行/等待，也会播放。

测试入口：

- 右键托盘图标仍可点击 `测试完成烟花` 验证动画本身。
- 正式触发路径来自全局聚合状态转换。

未进入 P4 的内容：

- 冷却、用户开关、减少动画、全屏和勿扰策略。

## P5：策略和边界情况

已实现内容：

- 增加 `CelebrationPolicy`。
- 完成烟花开关保存到 `HKCU\Software\CodexStatusLight\FireworksEnabled`。
- 右键菜单增加 `完成烟花效果 > 启用`。
- 自动触发烟花时检查用户开关。
- 默认冷却时间为 5000ms。
- 检查 Windows 减少动画设置。
- 检查 `SHQueryUserNotificationState` 的忙碌、全屏、演示和安静时段状态。
- 补充前台窗口全屏检测。
- 监听 `TaskbarCreated`，Explorer 重启后重新添加托盘图标。
- 覆盖窗口处理 `WM_DPICHANGED`，单次动画期间不重建场景。
- 被策略抑制的烟花不排队补放，只记录诊断原因。
- 诊断信息输出开关、冷却、动画允许状态、通知状态和最近抑制原因。

测试入口：

- 右键托盘图标，打开 `完成烟花效果 > 启用` 可启停自动烟花。
- `复制诊断信息` 可查看当前策略状态和最近抑制原因。

仍需人工视觉确认：

- Windows 11 多显示器和非 100% DPI 下的实际托盘锚点位置。
- 全屏应用、演示模式和系统勿扰状态下的真实系统行为。

## 测试覆盖

已加入 `StatusLight.exe --self-test-web`：

- 成功完成触发庆祝。
- 失败完成不触发庆祝。
- 取消完成不触发庆祝。
- 有其他运行任务时，成功完成只记录待庆祝，不立即播放。
- 全局最终进入完成态后，延迟的成功庆祝播放一次。
- 一次刷新内快速成功完成时，在启动基线之后仍可触发。
