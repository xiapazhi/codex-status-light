# 完成烟花效果

## P0：托盘锚点和透明窗口

已实现内容：

- 沿用现有托盘图标 `hWnd + uID` 定位，不创建第二个托盘图标。
- 使用 `Shell_NotifyIconGetRect` 获取托盘图标真实矩形。
- 读取图标所在显示器、工作区和 DPI。
- 创建 `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TOPMOST` 透明覆盖窗口。
- 使用 32 位顶向下 BGRA DIB 和预乘 Alpha 绘制 P0 柔和圆点。
- 定位失败按立即、80ms、160ms 最多三次尝试；失败只记录诊断，不猜测位置。
- 播放完成后隐藏覆盖窗口并停止烟花定时器。
- “复制诊断信息”追加 Celebration 诊断字段。

测试入口：

- 右键托盘图标，点击 `测试完成烟花`。
- 预期在托盘图标上方出现约 1 秒柔和圆点。
- 覆盖窗口不抢焦点、不拦截鼠标、不进入任务栏和 Alt+Tab。

未进入 P0 的内容：

- 火箭升空、尾焰、主爆炸、二次爆点和余辉。
- 成功、失败、取消的正式状态接入。
- 用户开关、冷却、减少动画、全屏和勿扰策略。

## P1：点火与升空

已实现内容：

- 增加 `FireworkAnimator`、`FireworkScene` 和 `FireworkRenderer`。
- 火箭从托盘锚点发射，使用 `EaseOutCubic` 前快后慢升空。
- 轨迹带轻微横向弧线。
- 点火阶段生成短寿命暖色粒子。
- 升空阶段每帧生成 2～4 个尾焰粒子。
- 尾焰使用指数阻力、重力、短拖尾和自然淡出。
- 渲染器负责 DIB、预乘 Alpha、软光点和拖尾；overlay 只负责透明窗口和 `UpdateLayeredWindow`。
- 检测到 500ms 以上大帧间隔时直接结束动画，避免休眠恢复后粒子跳飞。

测试入口：

- 右键托盘图标，点击 `测试完成烟花`。
- 预期能看到从托盘图标附近点火、火箭升空和连续尾焰。

未进入 P1 的内容：

- 主爆炸、冲击波、流星粒子、二次爆点和余辉。
- 正式成功状态接入和成功/失败/取消区分。
- 冷却、用户开关、减少动画、全屏和勿扰策略。
